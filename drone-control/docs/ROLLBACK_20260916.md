```bash

```

`app/page.tsx`는 두 커밋 어디에도 들어있지 않다. 작업 트리에 수정된 채로 남아 있다.
확인: `git log --oneline 7f3d713..HEAD -- app/page.tsx` → 결과 없음.

### 통째로 되돌리기

```bash
# 현장 수정 전체를 버리고 배포 기준선으로
git reset --hard 7f3d713

# 2단계만 버리고 1단계는 남기기
git reset --hard eac24ac

# 되돌리되 기록은 남기기 (커밋을 지우지 않음)
git revert --no-commit HEAD
```

`--hard`는 작업 트리를 덮어쓴다. `app/page.tsx` 수정이 날아가므로 먼저 확인할 것.
